### 📦 如何建立数据库以运行设备管理系统

请依照以下步骤在你的本地环境（例如 XAMPP）建立数据库并导入表结构：

#### 1️⃣ 打开 phpMyAdmin：

1. 启动 **XAMPP**。
2. 开启 **Apache** 和 **MySQL**。
3. 点击 **“Admin”** 进入 phpMyAdmin。

#### 2️⃣ 创建数据库：

1. 在 phpMyAdmin 左边点击 **“New”**。
2. 输入数据库名称：`devicesmanagement`
3. 点击 **Create**。

#### 3️⃣ 创建数据表 `devices`：

进入 `devicesmanagement` 后，点击 SQL，复制并执行以下 SQL 语句来创建表：

```sql
CREATE TABLE devices (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100),
    type VARCHAR(50),
    serial_number VARCHAR(100),
    model VARCHAR(100),
    asset_tag VARCHAR(50),
    purchase_date DATE,
    warranty_end DATE,
    lifespan VARCHAR(50),
    status VARCHAR(50),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```
✅ 接下来

确保你的 PHP 代码里连接的是：

```php
$conn = new mysqli("localhost", "root", "", "devicesmanagement");
```

然后就可以正常运行项目啦！
